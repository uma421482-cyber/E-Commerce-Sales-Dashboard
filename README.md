# E-Commerce Sales Dashboard — Power BI

## Project Overview
An interactive Power BI dashboard analyzing e-commerce business performance
across sales, revenue, channel distribution, and product category trends.

## Dataset
- Orders data with product categories, sales channels, and monthly transactions
- Categories: Fashion, Electronics, Accessories
- Channels: Online, In-store

## Key Metrics Tracked
| KPI | Value |
|---|---|
| Total Sales | 1,50,300 units |
| Total Revenue | ₹31,800 |
| Average Order Value | ₹21.47K |
| Total Orders | 7,028 |
| Conversion Rate | 0.96% |
| Profit Margin | 21.16% |

## Key Business Insights
- Online channel drives 95% of sales vs 4.99% in-store
- Fashion category accounts for 98.49% of total visitor traffic
- Conversion rate at 0.96% is below industry benchmark of 1–3%
- Revenue fluctuates significantly (17.8K → 1.6K → 11.8K) despite stable order volume
- Month 8 shows decline in both orders and revenue — signals potential churn or seasonality

## Tools Used
- Power BI Desktop
- DAX (calculated measures)
- Power Query (data transformation)
- Data Modeling

## Dashboard Features
- KPI cards for at-a-glance metrics
- Monthly trend analysis (combo bar + line chart)
- Category breakdown via donut chart
- Channel performance comparison
- Product-level filter slicer
